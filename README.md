# Trendwatcher — AI Market Intelligence

**От рыночного сигнала до рекламной стратегии за несколько минут.**
УТП: **Signal → Evidence → Insight → Campaign.**

Trendwatcher собирает публикации о рынке через веб-поиск, группирует их в независимые наблюдения (отделяя перепечатки), формирует и ранжирует тренды, а затем превращает каждый тренд в продуктовую гипотезу и концепцию рекламной кампании, привязанную к доказательствам.

## Запуск

```bash
npm install
cp .env.example .env.local   # впишите OPENAI_API_KEY (необязательно — демо работает без него)
npm run dev                  # http://localhost:3000
```

Продакшен-сборка: `npm run build && npm start`. Тесты: `npm test`.

| Переменная | Назначение |
|---|---|
| `OPENAI_API_KEY` | Ключ OpenAI. Используется только на сервере. Без него доступен демо-режим. |
| `OPENAI_MODEL` | Модель с поддержкой Responses API + `web_search` (по умолчанию `gpt-4.1`). |

## Пользовательский путь

1. **Research Studio** (`/new`): рынок, бренд, позиционирование, география, период (30/90/180/365), вопрос, ЦА, 7 пресетов категорий, примеры вопросов в один клик, запуск демо без API.
2. **AI Research Engine** (`/api/research`, NDJSON-стрим реальных этапов):
   1. Поисковая стратегия: 6 запросов по ракурсам (поведение, инновации, коммуникации, исследования, конкуренты, культура).
   2. Сбор данных: OpenAI Responses API + `web_search`. **Принимаются только URL, которые есть в фактических `url_citation` поиска**; остальное отбрасывается и считается в статистике.
   3. Кластеризация: публикации → независимые наблюдения → тренды (LLM) + **детерминированная страховка**: дубли URL (в т.ч. utm/amp/www) удаляются, наблюдения с общей публикацией, общим первоисточником (`originHint`) или почти идентичным заголовком объединяются.
   4. Проверка доказательств: публикации, независимые наблюдения, перепечатки, первичные источники, свежесть, ограничения. Тренд из одного наблюдения помечается как слабый сигнал.
   5. Скоринг: LLM оценивает 5 компонентов (0–100, с обоснованием), **итог считается программно** (30/25/20/15/10). Оценка доказательности ограничивается сверху числом независимых наблюдений (1 → ≤40, 2 → ≤65, 3 → ≤85).
   6. Для каждого тренда: продуктовая гипотеза и концепция кампании. Ссылки кампании на доказательства валидируются по ID источников тренда.
3. **Market Intelligence Dashboard** (`/research/[id]`): executive summary, 5 KPI без двойного счёта, Interactive Trend Radar (4 зоны, tooltip, клик → тренд), Trend Explorer (сортировка и фильтры), методология и ограничения, экспорт Markdown / печать в PDF.
4. **Trend Intelligence** (`/research/[id]/trend/[trendId]`): Overview, Evidence Explorer (дерево «наблюдение → первоисточник + перепечатки»), Score Breakdown, Product Opportunity, Campaign Studio (факты отдельно от творческих гипотез, копирование брифа, альтернативная концепция).
5. **Campaign Studio** (`/campaigns`), **Trend Explorer** (`/explorer`), **Research History** (`/history`, localStorage).

## Архитектура

- Next.js 15 (App Router), TypeScript, Tailwind CSS, Recharts, Lucide, Zod. Компоненты в стиле shadcn/ui написаны вручную (`components/ui.tsx`).
- `lib/types.ts`: Zod-схемы `Research`, `Trend`, `Observation` (сигнал), `Source`, `ProductOpportunity`, `CampaignConcept`.
- `lib/engine.ts`: серверный пайплайн; `lib/openai.ts`: клиент Responses API (ключ только на сервере).
- `lib/sanitize.ts`: валидация ответов модели, проверка ID и URL; `lib/analytics.ts`: скоринг, доказательность, дедупликация, KPI.
- `lib/demo.ts`: встроенное демо Pedigree × США. **Все публикации синтетические**, помечены `[ДЕМО]`, без ссылок.

## Тесты

`npm test`: 14 unit-тестов (скоринг и пороги, cap доказательности, нормализация URL, слияние перепечаток, отбрасывание выдуманных URL, санитизация ID, KPI без двойного счёта, а также пайплайн на моке OpenAI: успех, нет результатов, ошибка поиска, 401, отсутствие ключа).

## Ограничения

- Реальный поиск зависит от модели с инструментом `web_search`; без ключа работает только демо.
- Даты, география и тип доказательства извлекаются моделью из найденных страниц и могут быть неточны; URL гарантированно взяты из результатов поиска.
- Независимость наблюдений определяется моделью плюс эвристиками; если её нельзя установить, наблюдение помечается как неподтверждённое.
- Trend Score — эвристика приоритетности, а не измерение роста рынка.
- История хранится в localStorage конкретного браузера.
