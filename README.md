# Trendwatcher — AI Market Intelligence

**От рыночного сигнала до рекламной стратегии за несколько минут.**
УТП: **Signal → Evidence → Insight → Campaign.**

Trendwatcher собирает публикации о рынке через веб-поиск, группирует их в независимые наблюдения (отделяя перепечатки), формирует и ранжирует тренды, а затем превращает каждый тренд в продуктовую гипотезу и концепцию рекламной кампании, привязанную к доказательствам.

## Архитектура

```
Браузер ──► Next.js (Vercel): страницы + API /api/research (NDJSON-стрим этапов), /api/campaign, /api/status
                    │
                    ├─► Tavily Search API — реальные публикации (URL, заголовок, фрагмент, дата)
                    └─► LLM по OpenAI-совместимому API (по умолчанию Groq, бесплатно) — анализ и генерация
GitHub Pages (статическое зеркало) ──CORS──► тот же API на Vercel
```

- Ключи живут только на сервере (`TAVILY_API_KEY`, `LLM_API_KEY`), в клиентскую сборку не попадают.
- URL и даты публикаций берутся **только** из поискового API; модель добавляет краткое содержание и классификацию, но не может подставить ссылку или дату.
- Защита публичного сервиса: лимит на IP в час, дневной бюджет исследований, ограничение параллельных запусков, CORS allow-list, таймауты и повторы при 429/5xx, ротация моделей при исчерпании бесплатных лимитов.

## Запуск локально

```bash
npm install
cp .env.example .env.local   # впишите TAVILY_API_KEY и LLM_API_KEY
npm run dev        # http://localhost:3000
```

Без ключей работает только демо-исследование (отдельная кнопка); форма честно показывает, что реальный поиск недоступен.

## Публичное развёртывание (Vercel, бесплатный план)

1. Получите бесплатные ключи: Tavily — https://app.tavily.com (1 000 кредитов/мес, ~160 исследований), Groq — https://console.groq.com/keys.
2. https://vercel.com/new → Import Git Repository → `fluxx102/trendwatcher` (Framework: Next.js, остальное по умолчанию).
3. В Environment Variables добавьте `TAVILY_API_KEY` и `LLM_API_KEY` (остальные переменные — по желанию, см. `.env.example`). Deploy.
4. Откройте `https://<проект>.vercel.app/api/status` — должно быть `"available": true`.
5. Чтобы зеркало на GitHub Pages тоже выполняло реальный поиск: GitHub → Settings → Secrets and variables → Actions → Variables → `API_BASE_URL = https://<проект>.vercel.app`, затем перезапустите workflow «Deploy demo to GitHub Pages».

Если у ключей нет или бюджет исчерпан, приложение не подменяет результаты демо-данными: оно показывает причину и отдельную кнопку демо.

## Пользовательский путь

1. **Research Studio** (`/new`): рынок, бренд, позиционирование, география, период (30/90/180/365), вопрос, ЦА, 7 пресетов категорий, примеры вопросов в один клик, запуск демо без API.
2. **AI Research Engine** (`/api/research`, NDJSON-стрим реальных этапов):
   1. Поисковая стратегия: 6 запросов по ракурсам (поведение, инновации, коммуникации, исследования, конкуренты, культура).
   2. Сбор данных: OpenAI Responses API + `web_search`. **Принимаются только URL, которые есть в фактических `url_citation` поиска**; остальное отбрасывается и считается в статистике.
   3. Кластеризация: публикации → независимые наблюдения → тренды (LLM) + **детерминированная страховка**: дубли URL (в т.ч. utm/amp/www) удаляются, наблюдения с общей публикацией, общим первоисточником (`originHint`) или почти идентичным заголовком объединяются.
   4. Проверка доказательств: публикации, независимые наблюдения, перепечатки, первичные источники, свежесть, ограничения. Тренд из одного наблюдения помечается как слабый сигнал.
   5. Скоринг: LLM оценивает 5 компонентов (0–100, с обоснованием), **итог считается программно** (30/25/20/15/10). Оценка доказательности ограничивается сверху числом независимых наблюдений (1 → ≤40, 2 → ≤65, 3 → ≤85).
   6. Для каждого тренда: продуктовая гипотеза и концепция кампании. Ссылки кампании на доказательства валидируются по ID источников тренда.
3. **Market Intelligence Dashboard** (`/research/[id]`): executive summary, 5 KPI без двойного счёта, Interactive Trend Radar (4 зоны, tooltip, клик → тренд), Trend Explorer (сортировка и фильтры), методология и ограничения, экспорт Markdown / печать в PDF.
4. **Trend Intelligence** (`/research/[id]/trend/[trendId]`): Overview, Evidence Explorer (дерево «наблюдение → первоисточник + перепечатки»), Score Breakdown, Product Opportunity, Campaign Studio (факты отдельно от творческих гипотез, копирование брифа, альтернативная концепция).
5. **Campaign Studio** (`/campaigns`), **Trend Explorer** (`/explorer`), **Research History** (`/history`, localStorage).

## Архитектура

- Next.js 15 (App Router), TypeScript, Tailwind CSS, Recharts, Lucide, Zod. Компоненты в стиле shadcn/ui написаны вручную (`components/ui.tsx`).
- `lib/types.ts`: Zod-схемы `Research`, `Trend`, `Observation` (сигнал), `Source`, `ProductOpportunity`, `CampaignConcept`.
- `lib/engine.ts`: серверный пайплайн; `lib/openai.ts`: клиент Responses API (ключ только на сервере).
- `lib/sanitize.ts`: валидация ответов модели, проверка ID и URL; `lib/analytics.ts`: скоринг, доказательность, дедупликация, KPI.
- `lib/demo.ts`: встроенное демо Pedigree × США. **Все публикации синтетические**, помечены `[ДЕМО]`, без ссылок.

## Дизайн-система

- **Токены:** CSS-переменные в `app/globals.css` (цвета, поверхности, приоритет, easing), Tailwind только ссылается на них (`tailwind.config.ts`).
- **Типографическая шкала:** 11 / 12 / 13 / 14 / 15 / 17 / 20 / 24 / 32 / 44 px (`text-micro` … `text-4xl`). Inter для интерфейса, Source Serif 4 для заголовков.
- **Цвет:**
  - приоритет — ординальная одноцветная шкала `#073a36 → #5fac9f`, проверена валидатором палитр (монотонная светлота, один тон, контраст светлого конца ≥ 2:1);
  - amber и rose зарезервированы для статусов доказательности и всегда идут с иконкой и подписью;
  - весь текст ≥ 4.5:1.
- **Motion:**
  - ease-out `cubic-bezier(0.23, 1, 0.32, 1)`, интерфейсные переходы 150–300 мс, анимируются только transform и opacity;
  - press-feedback `scale(0.97)`, hover-lift только на устройствах с курсором, ступенчатое появление карточек, сегментированные контролы со скользящим индикатором, анимированные Trend Score и шкалы;
  - `prefers-reduced-motion` отключает всё.
- **Адаптивность:**
  - на мобильных — нижняя панель вкладок с подписями и safe-area;
  - на карте трендов по умолчанию открыта таблица;
  - фильтры прокручиваются горизонтально, горизонтального переполнения нет от 320 px.
- **Доступность:** skip-link, видимый focus-ring, `aria-current`/`aria-pressed`/`role=radio`, у карты есть текстовое описание и табличная альтернатива; axe-core (WCAG 2.1 AA) — 0 нарушений на всех страницах.

## Тесты

`npm test` — 20 автоматических тестов **на моках** (без сети): скоринг и пороги, cap доказательности, дедупликация URL, слияние перепечаток, разделение «тематических» групп разных первоисточников, URL/даты только из поиска, валидация ID, KPI без двойного счёта, пустой честный результат, ротация моделей при дневном лимите, NO_RESULTS / SEARCH_FAILED / AUTH / NO_API_KEY, rate limit, параллелизм и CORS.

Живые интеграционные проверки (реальные Tavily + Groq) выполнялись вручную на локальном сервере — см. отчёт в истории коммитов; они не входят в `npm test`, чтобы не тратить бесплатные лимиты.

## Ограничения

- Реальный поиск зависит от модели с инструментом `web_search`; без ключа работает только демо.
- Даты, география и тип доказательства извлекаются моделью из найденных страниц и могут быть неточны; URL гарантированно взяты из результатов поиска.
- Независимость наблюдений определяется моделью плюс эвристиками; если её нельзя установить, наблюдение помечается как неподтверждённое.
- Trend Score — эвристика приоритетности, а не измерение роста рынка.
- История хранится в localStorage конкретного браузера.
